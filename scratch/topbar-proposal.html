顶栏（ACTIVE PROJECT 区）美化提案

红框这一条的问题不是"东西摆得不好看"，而是边界语言不统一：顶栏自己没有任何边界（渐变收尾色 = 内容区底色，没有 1px 分隔线），而它下面紧挨着的中栏第一张卡（智能体主控）却带着圆角 + 描边。于是视线从上往下走时，会在顶栏下沿处"踩空"，然后突然落进一套完全不同的卡片语言里。另外中栏的右侧竖线只从顶栏下沿才起，出现"断头"。

现状实测

顶栏 h-16（64px）横跨中栏 + 主区，背景是 linear-gradient(180deg, surface-1 → surface-0)，收尾色与内容区底色完全一致 → 没有任何横向收口。中栏右边界线从 y≈69 才起，而左侧 nav 的竖线是从 y=0 贯通到底的。

顶栏左侧改成一张与「智能体主控」同款的胶囊卡（同 9px 圆角、同 brand 16% 描边、同 padding），并删掉 9px 全大写英文 eyebrow —— 它是整个中文界面里唯一一处全大写英文标签。统计移到右侧与「首页」同组，左右重量才平衡。

提案 C · 顶栏不再横跨结构根治

让中栏自己有一个 64px 高的头部（放智能体卡），与右栏顶栏同高、同底线。这样横线在两栏之间连续贯通、竖线从 y=0 通到底，整个上半区变成一套干净的正交网格，不再有"半截框"和"断头线"。代价是要把顶栏从 Panel main 顶层挪进右侧内容列，改动比 A/B 大。
