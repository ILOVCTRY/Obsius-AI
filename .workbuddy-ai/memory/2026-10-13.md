# 2026-10-13

## 逆向工作台补「意图」查看入口

- 问题：`IntentsPane`（`webui/src/views/blackboard/IntentsPane.tsx`，当日新建）只挂在 `Blackboard.tsx` 的「意图」tab；但 `App.tsx` 有 profile 分叉——`profile === "rev-generic"`（research 轨 + binary 能力）时左导航「黑板」位渲染的是 `ReverseWorkbench`，`Blackboard` 根本不挂载 → 逆向轨的意图清单从任何入口都不可达。
- 改动（`webui/src/views/reverse/ReverseWorkbench.tsx`）：
  - import 复用 `../blackboard/IntentsPane`；
  - `mode` 联合类型加 `"intents"`；
  - subnav 追加 `["intents", "意图"]`（现为：逆向分析｜功能树｜攻击链｜蓝图｜业务逻辑｜意图）；
  - 渲染分支 `mode === "intents"` → `<div className="min-h-0 flex-1"><IntentsPane pid={pid} /></div>`（包一层保证 IntentsPane 根 `h-full` 高度链成立）。
- 文档：`webui/CLAUDE.md` 同步——Blackboard 条目补「rev-generic 轨本 tab 不可达」的说明，`views/reverse/` 条目 subnav 列表补「功能树｜意图」（原文还漏了当日新增的功能树）。
- 验证：`tsc -b` 零错误；`npm run build` 通过并重建 `webui/dist`（平台「dist 静态优先」，不重建看不到改动）。
- 关键认知：**逆向轨的「黑板」= ReverseWorkbench**，黑板上的任何 tab 级入口在逆向轨都必须另行在工作台里补，否则不可达。
