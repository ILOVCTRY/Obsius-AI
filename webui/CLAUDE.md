- **弹窗内长文本溢出 = grid min-content 撑爆，用 `wrap-anywhere` 不用 `break-words`**（2026-09-22）：`AlertDialogContent` 是 grid——内容含超长不可断 token（URL/base64）时，token 的 min-content 宽度沿「p → Description → Header（grid item，overflow visible）」链把轨道撑爆，盒子自身被撑宽后 `line-clamp`/`overflow-hidden` 裁剪形同虚设，文本横向画出弹窗盖到页面上（删除任务确认弹窗溢出 bug 的根因）。修法=文本元素加 `wrap-anywhere`（overflow-wrap:anywhere 才收窄 min-content；`break-words` 按 spec 不影响 min-content，对 grid/flex 撑爆无效）；`AlertDialogContent` 已加 `max-h-[85dvh] overflow-y-auto` 兜底（overflow-y 非 visible 会把 overflow-x 折算成 auto，横向同样挡住，超高弹窗也从「出屏不可滚」变为弹窗内滚动）。
