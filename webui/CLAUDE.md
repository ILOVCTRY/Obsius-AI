## 坑

- **高度链**：App.tsx 主区包装统一为 `h-full w-full`（rev 另加 overflow-hidden），不再有"普通黑板是滚动文档"特例；画布类定高视图一路 `min-h-0` 不可断。
- **@xyflow/react v12 受控节点**：受控 `nodes` 按引用比较，重渲染给不带 `measured` 的新节点会清测量/handleBounds → 边卸载；必须在 `onNodesChange` 回收 dimensions（字段名 `ch.dimensions`）回灌派生节点。EdgeLabelRenderer 容器 pointer-events:none，标签要自加 pointer-events-auto。**无头/自动化排查图问题先查 `document.visibilityState`**：隐藏标签页冻结 rAF 与 ResizeObserver 首包，节点测量与边挂载全停（CDP `Page.bringToFront`+`Emulation.setFocusEmulationEnabled` 后恢复，非产品缺陷）。详见 views/blackboard、views/live 与 reverse/chains 的 CLAUDE.md。
- **react-resizable-panels 是 v4 API**：`Group(orientation)/Panel/Separator`（非旧版 PanelGroup/PanelResizeHandle）；Panel 的 number 尺寸=像素、带单位字符串=%。
- **radix Tabs 在 mousedown/focus 激活不是 click**：JS 合成 `.click()` 不切 tab，用真实点击或 `.focus()`。
- **Tailwind v4.3 起 `bg-[--var]` 简写被移除**（4.3.3 实测）：编译成 `background-color: --status-x`（缺 `var()`，声明非法被浏览器丢弃）——类名在 DOM 上、computed 却是 transparent，**CSS 无报错、灯/语义色全部静默失效**（2026-09-16 状态灯不显示的根因，重启平台换新编译器后显形）。全库已统一为 v4 变量简写 `bg-(--status-x)`/`text-(--status-x)`（括号成对）；新增类名禁止再写 `-[--x]`。**变量本身也必须先定义**：`--status-ok` 此前漏定义，`bg-(--status-ok)` 同样静默透明（2026-09-18 作战计划「运行中」绿灯隐形的根因，index.css 已补）——新增状态色先在 index.css 状态语义色块加变量再用。
- shadcn `add` 可能把 cn 导入写成 `"cn"` 包，改回 `@/lib/utils`；tsconfig.app.json 不写 baseUrl。
- Vite 只听 `::1`，curl 127.0.0.1:5173 拒连；中文 JSON body 用 Python/httpx 测，勿用 Git Bash curl 管道（乱码成假象）。
- **设置页按轨/包拉列表必须带竞态守卫**（2026-09-20）：SettingsView 初始 track 硬编码 "ctf"，从项目进入时先拉 ctf 再异步跟项目切轨——旧轨响应晚到会覆盖新轨列表（曾致「进项目设置页角色列表显示 ctf 角色」）。RolesPane/SkillsPane/MatrixPane/RouteTester 四处均已用 `let alive = true` + effect cleanup 丢弃过期响应（与 ReverseWorkbench 取数同款模式）；新增按 track/cap 拉列表的 Pane 照抄此守卫。
- **Radix `AlertDialogAction` 点击即关弹**（2026-09-20）：Action 的默认语义是 click 后立刻 close（触发 `onOpenChange(false)`）——若删除失败原因渲染在弹窗内，错误到达时弹窗已关，用户只见「关了没删」零反馈（曾致「删除项目没用」，实际后端 422 目录被占用但无人看见）。二选一：①弹窗内要显失败原因 → Action 的 onClick `e.preventDefault()` 拦关弹，成功才 `setConfirmTarget(null)`（ProjectsView/ChainView 此模式，均 preventDefault + 失败原因 `<p>` 留弹窗）；②失败原因显弹窗外 → 沿用 TaskBoard 的普通 Button 替代 Action。SettingsView 的 AlertDialogAction + finally 关弹属 ②变体（err 落主面板，可见）。
- **删项目 422「目录被占用」的排查口诀**（2026-09-20）：WinError 5/32 = 有进程攥着 `workspaces/<proj>/` 句柄（SQLite WAL 的 -wal/-shm 或进程 cwd 在目录内）——先查是否有**多个 serve.py 并存**（游离副本开过项目连接即锁死删除）与遗留测试/工具进程，`Get-CimInstance Win32_Process` 看 CommandLine，强杀后重试。
