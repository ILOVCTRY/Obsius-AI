# views/live/（直播间：直播流 + 任务树）

> 直播间第二张 React Flow 图：任务尝试树 v2 意图驱动（目标 → 意图 → 检验结果，新发现下长新意图，单向树）。
> 经 `React.lazy` 从 LiveRoom 分包加载，@xyflow/react 不进直播间主包。

## 入口

- `LiveRoom.tsx` 第一行页签栏右侧「直播｜任务树｜协调」分段切换（原生 button，不用 radix Tabs——mousedown 激活坑见 webui/CLAUDE.md）；切到 tree/coord 时只保留页签行，主区 `<Suspense>` 渲染 `<TaskTreeView …/>` / `<CoordinationPane pid={pid} onOpenSession={…} />`（后者点会话/绑定节点切回直播视图）。
- `wsBump`（task.*/message.inbox/session.* 事件计数）去抖重拉 + 组件内 3s 轮询兜底（本组件不另开 WS）。
- 原「任务流」（TaskFlow 五件套：TaskFlow/TaskNode/TaskFlowEdge/flowModel/flow.css）已随任务尝试树退役（2026-09-27）；后端 graph.task_graph 函数删除，GET /task-graph 端点 410 过渡指路 /tree/{task_id}。

## 关键约定

- **v12 受控节点契约**：onNodesChange 必须回收 `ch.dimensions` 存 measuredById 并回灌每个派生节点（`measured` 字段），否则重渲染清测量、边整体卸载；测量兜底用 `useUpdateNodeInternals` + setTimeout tick 链强测（≤40×60ms，**不要用 rAF**，隐藏页会冻 rAF/RO）；全部节点 measured 后 fitView 一次（padding 0.12, maxZoom 1），ready 门只控 fitView 时机，**边始终供给，不要两阶段喂空边**。
- 数据模型类型在 `webui/src/lib/types.ts` 的 `TaskTree/TaskTreeNode`（intent/finding/bucket 三 variant 联合；TaskGraph*、v1 的 Step/Action/Intent 细分类型已随退役删除）；后端组装在 `core/blackboard/tasktree.py`（纯只读；发现归属优先级与门禁口径见 blackboard/CLAUDE.md）。
- 节点卡样式对齐 AttackPath 卡（状态徽章/色条口径沿用四态 open 灰/claimed 青/done 绿/failed 红）。
