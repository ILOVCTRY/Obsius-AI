# docs/

> 除 DESIGN.md 与各目录 CLAUDE.md 之外的长文档：架构深化、领域研究笔记、评测记录、操作手册。`plans/` 为**方案目录**（设计讨论收敛的待实施设计，走打磨→实施路线，见其 CLAUDE.md）。

## 约定

- 设计决策的唯一真相源是根目录 `DESIGN.md`——本目录存放其展开与佐证，不存放与 DESIGN.md 冲突的结论；若研究推翻了 DESIGN.md 的决策，先更新 DESIGN.md。唯一例外：`plans/` 下方案文档允许超前于现状（实施落地时才回写 DESIGN.md）。
- 文件命名建议：`<主题>.md`（如 `runtime-isolation.md`、`nyuctf-eval.md`）。
- `paper-qiangwang2026.md`：强网征文 2026 论文工作文档（大纲/实验进度/素材索引），截稿 2026-10-31；论文相关讨论以此文为落点，勿散落会话。
