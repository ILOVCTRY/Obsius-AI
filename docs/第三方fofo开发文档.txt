系统简介
本系统是FOFA的中转代理平台，支持在线网页查询和API查询，其中API查询接口调用方式与官网完全一致，并且兼容各种第三方查询工具。
使用第三方工具时，只需要将官网的api地址换成本站的api地址（https://fofoapi.com）即可。
符号、语法、字段支持与否
支持查的询符号（6个）：=、==、&&、||、!=、()

不支持的查询符号（1个）：*=

支持的查询语法（54个）：ip、port、domain、host、os、server、asn、org、is_domain、is_ipv6、app、fid、product、category、type、cloud_name、is_cloud、is_fraud、is_honeypot、protocol、banner、base_protocol、title、header、header_hash、body、body_hash、js_name、js_md5、cname、cname_domain、icon_hash、status_code、icp、country、region、city、cert、cert.subject、cert.issuer、cert.subject.org、cert.subject.cn、cert.issuer.org、cert.issuer.cn、cert.domain、cert.is_equal、cert.is_valid、cert.is_match、cert.is_expired、jarm、tls.version、tls.ja3s、after、before

不支持的查询语法（11个）：sdk_hash、after && before、port_size、port_size_gt、port_size_lt、ip_ports、ip_country、ip_region、ip_city、ip_after、ip_before

支持展示的字段（40个）：ip-IP地址、port-端口、protocol-协议名、location.country-国家代码、location.country_name-国家名、location.region-区域、location.city-城市、location.longitude-经度、location.latitude-纬度、asn-ASN编号、org-ASN组织、host-主机名、domain-域名、os-操作系统、server-Server、icp-ICP备案号、title-网站标题、jarm-JARM指纹、header-Header、banner-Banner、cert-证书、base_protocol-基础协议、Iink-URL链接、cert.issuer.org-证书颁发者组织、cert.issuer.cn-证书颁发者CN、cert.subject.org-证书持有者组织、cert.subject.cn-证书持有者、CNtls.ja3s-JA3S指纹、tls.version-TLs版本、cert.sn-证书序列号、cert.not before-证书生效时间、cert.not_after-证书到期时间、cert.domain-证书根域名、header hash-Header Hash、banner hash-Banner Hash、banner fid-Banner FlD、cname-CNAME、lastupdatetime-最后更新时间、product-产品名、product_category-产品分类

不支持展示的字段（10个）：product.version-产品版本、icon hash - lcon Hash、cert.is_valid-证书是否有效、cname_domain-CNAME域名、body-网站正文、cert.is_match-证书颁发者匹配、cert.is_equal-证书域名匹配、icon -lcon图标、fid - FID、structinfo-结构化信息
特别提醒：默认最大支持输出10000条数据，当展示字段中包含以下字段时，最大输出数据条数会减少：

API 概览
本系统提供以下API接口：
1. 查询接口 (/api/v1/search/all) - 与 FOFA 搜索功能对应
2. 连续翻页接口 (/api/v1/search/next) - 与 FOFA 搜索功能对应
3. 统计数据接口 (/api/v1/search/stats) - 获取查询结果统计信息
4. Host查询接口 (/api/v1/host/{host}) - 获取指定主机的详细信息
5. 用户信息接口 (/api/v1/info/my) - 支持返回实际套餐剩余和到期时间
配额限制
- 查询接口（/api/v1/search/all）消耗：与返回结果数量相等的查询配额 / 一次查询次数
- 连续翻页接口（/api/v1/search/next）消耗：与返回结果数量相等的查询配额 / 一次查询次数
- 统计聚合接口（/api/v1/search/stats）消耗：固定消耗1000个查询配额 / 一次查询次数
- Host查询接口（/api/v1/host/{host}）消耗：固定消耗1000个查询配额 / 一次查询次数
- 用户信息接口（/api/v1/info/my）不消耗查询配额
每日查询限制
- 根据不同套餐限制，可在fofoapi.com实时查看配额信息
- 用户信息接口（/api/v1/info/my）不消耗配额
- 每日限制在北京时间0点重置
请求速率限制
- 理论不限制请求速度，根据自身查询语句情况酌情调整。
- 每个key允许的并发数量由总活跃用户决定，动态调整。
- 系统会根据请求压力动态启用备用key。
- 请控制并发池在一个合理的范围，请求过快也会被扣除相应的查询配额
- 且用且珍惜
- 脚本请检查返回内容中是否包含"已用完"的字样，如果包含请停止脚本，否则有可能遭遇封禁。
关于套餐 
以月卡举例分为两种套餐：
1. 每天200次，无总条数限制。适合查询大资产用的，但是它的次数少一点
  1. 除了每天次数以外无其他限制。
2. 每天500次，有总条数限制（有效期内100万条数据），但是不适合查大资产
  1. 如果每次查询都是大资产，都有 1 万条以上的内容，那么极限情况下，100 次查询就会消耗完毕。
