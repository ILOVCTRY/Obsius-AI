## 约定

- 时间 UTC ISO（`now()`）；ID `<前缀>-<12hex>`（`new_id()`）；外键开启。
- 写靠 WAL + busy_timeout + BEGIN IMMEDIATE + Lock；读多连接；多进程需换 Postgres。
- `close()` 只关当前线程连接；`close_all()` 关全部并置**关闭闸门**——之后 `.conn` 拒绝惰性重连（抛 `BlackboardClosedError`，闸门锁内双重检查）。**Windows 删项目目录前必须 close_all**，否则 WS/轮询线程会重开连接锁死 db。`Project.bb` property 同样有闸门。
- 三层数据纪律：headless 全量函数只活在 artifacts/decompiler-cache 的 JSON，**不进 SQLite**；func_kb 只存分析过的函数；finding 逆向结论挂 binary 资产、evidence 带 func_id+address。
- 事件 kind 见各文件条；消费方按 kind 过滤（`llm.usage`/`budget.soft_warning`/`task.*`/`func.updated`/`finding.*`/`asset.*`/`verify.result`/`message.inbox`/`chain.*`/`blueprint.*`/`logic_block.*` 等）。

## 坑

- **资产维护工具**：`delete_asset(asset_id)` 只删非 binary 叶子且拒绝仍被 findings 引用的资产；binary 走 `delete_binary` 样本流程。`merge_assets(project_id, source_asset_id, target_asset_id, reason=)` 单事务内迁移 findings、intents 资产锚点和子资产，源资产快照写入目标 `meta.aliases` 后删源行并落 `asset.merged`；拒绝 binary、跨项目、目标为源后代、发现去重键冲突和子资产重复。
- upsert_asset 去重键含 parent_id；补挂/改 meta 用 find_asset + update_asset_meta/set_asset_parent，勿重复 upsert。
- tests/test_blackboard.py 含旧 DB 行映射护栏；改 schema 必须升版本 + 幂等迁移。
