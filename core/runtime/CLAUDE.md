# core/runtime/

> 执行环境层（DESIGN.md §7）：唯一命令出口。Agent 无裸 shell，一切命令经网关 + 策略校验。

## 文件

| 文件 | 职责 |
|------|------|
| `policy.py` | 隔离等级 **L0 host < L1 wsl < L2 docker < L3 sandbox**（注意：L1-L3 一名已被本节占用，逆向复用三层因此命名 R1/R2/R3，见 DESIGN §9）；`allowed_runtimes(threat_class)`——trusted 全等级、untrusted 仅 docker/sandbox、**unknown 缺省按 malware_live 只允许 sandbox**（宁严勿松）；网络模式 none/fakenet/real，默认 none（**real 自 2026-10-01 起不再人工审批**，可直接经 run_cmd 指定） |

| `gateway.py` | `ExecutionGateway(backends=..., bb=?)`：按策略选 backend 执行，违例抛 `GatewayDenied`（Agent 侧回填 `[网关拒绝]` 改道，不炸循环）；**net=real 自 2026-10-01 起不再人工审批**（run_cmd 直接指定即放行；隔离等级/threat_class/网络模式合法性仍校验）；`allowed_runtimes_names(threat_class)`。**工作区隔离（W1/W2/W4）**：`run(..., workspace=)` host/wsl/docker 时先 pathguard 硬拒（`audit.deny{reason:"workspace-escape"}`）→ cwd 强制 `<ws>/scratch`、TEMP/TMP 重定向 `<ws>/.tmp`（wsl 走 `--cd` + TMPDIR 前缀，`windows_to_wsl_path` 换算；**docker 容器化 M0 2026-09-23**：挂载 `<ws>:/workspace` 读写 + cwd=`/workspace/scratch`，pathguard 切容器内 posix 语义校验）；command 事件补 `cwd`/`step`（step=执行器当前步号透传，D9 预检区间切分用）。**扫描限速纪律（2026-09-19 借鉴 dsh）**：工作区检查后调 `rateguard.check_rate(cmd)`，拒因非空即 `_audit_deny`（四规则见 rateguard 行；`audit.deny` 事件 Agent 改道协议零改动）。**事件时序（2026-09-18 直播间终端化）**：`command` 事件**执行前**落（带 `call_id`，前端直播可见「运行中」；被拒命令仍不落 command 只落 deny）；`command.result` 补 `call_id`+冗余 `cmd`（自含可独立渲染防上翻孤儿），stdout/stderr head 截断 500→2000；`_dispatch` 抛 BackendError 时 command 已落 result 缺失=前端「悬空运行中」语义诚实。**■ 即点即停（2026-09-19）**：`run(..., abort_event=)` 透传 backend——命令执行中置位即杀进程树立刻返回（`ExecutionResult.interrupted`+brief「被人手中断」+command.result 事件 `interrupted:true`），不等命令自然结束。**would_deny 干跑判定**：`would_deny(cmd, runtime, *, threat_class, net, workspace) -> str|None`——不执行不审计的策略校验（runtime 合法/隔离等级/非法 net/工作区逃逸/限速纪律），run() 内部复用同一方法，确保策略口径单一；net=real 可由 run_cmd 直接指定，隔离等级/threat_class/工作区与限速约束不变。**截断可见化（2026-09-20）**：`brief(limit=2000)` stdout/stderr 被切时尾部追加 `…[stdout 已截断：2000/3000 字符，请缩小窗口分段读]`——Agent 必须能察觉被切；标记刻意紧凑（+~40 字符/条），长格式会翻转 G3 摘要触发。**会话级常驻容器路由（P3，2026-10-07）**：`ExecutionGateway(containers=SessionContainerManager|None)`（默认 None=关闭）；`_dispatch` 里 `runtime=="sandbox"` **前置**恒走 `run_once`（L3 铁律永不经管理器），`runtime=="docker"` 且 `containers.enabled` 且 `session_id` 以 `sess-` 开头才走 `manager.exec`，其余（None/`chat-*`/`rev-workbench`/建容器失败返回 None）一律回落 `run_once`——绝不因新机制让命令失败 |
| `rateguard.py` | **限速纪律纯函数（2026-09-19）**：`check_rate(cmd) -> str|None`，`&&/||/;/|` 分段逐段查（复用 pathguard `_clean/_split_tokens`；`_binname` 取首 token basename 去 .exe）。四规则：nmap 全端口（-p- 变体）无 -T0..3/--max-rate/--max-parallelism/--scan-delay 拦；masscan --rate>1000 拦；ffuf 无 -rate/-rl 拦；hydra 无 -t 拦——**拒因一律带放行配方**（怎么改才放行）。**RATE_RULES 快照表（gateway-config-view M1，2026-09-23）**：tool → {requirement/params/hint/threshold} 单一事实源，校验函数读表组装拒因（`_reject`），`set(RATE_RULES)==set(_RULES)` 键一致性测试防新增工具忘登记；新增工具两表同步。纯静态检查不执行命令 |
| `backends.py` | `NativeBackend`（host/wsl 经 PowerShell，`--%` 停止解析坑见 DESIGN §9）、`WSLBackend`（信任级=宿主机）、`DockerBackend`（不可信代码默认）、`BackendError`、`DEFAULT_PENTEST_IMAGE`（docker runtime 默认镜像 `cyberstrike/pentest-box:0.1`，与 scripts/build_pentest_box.py 同步）。**协作取消（2026-09-19）**：`execute/run_once/exec_in` 均收 `abort_event`——Popen 轮询等待（`POLL_INTERVAL=0.2s` 即最大中断延迟），abort 置位或超时经 `_kill_tree` 杀进程树（Windows `taskkill /PID x /T /F` 防子进程留尸）；`ExecOutcome.interrupted` 标记。**管道排水（2026-09-23 死锁修复）**：stdout/stderr=PIPE 时 `_execute_piped` 起 daemon 线程持续消费——旧 `_wait_or_kill` poll 轮询从不读管道，输出超 64KB Windows 管道缓冲 → 子进程写阻塞+父进程等退出死锁到 timeout 杀树（实战 wsl grep 单行 120KB 挂 120.8s 实锤）；三后端共用。**wsl `--exec`（2026-09-23）**：`WSLBackend.execute` argv 走 `wsl.exe --exec bash -lc <cmd>`——默认包装层重新引用命令行时剥引号，bash 拿到裸命令把 `$var`/awk `$1`/`$$` 按 Linux 环境展开吞掉；`--exec` argv 直通引号保真。**NO_WINDOW_FLAGS（2026-09-23）**：模块常量 `subprocess.CREATE_NO_WINDOW`（POSIX=0），三后端+`_kill_tree` 的 taskkill 统一带上——窗口模式（pythonw/打包 exe）父进程无控制台可继承，不带标志每条命令弹 PowerShell 窗；标志对孙进程链生效，detector/decompiler 亦导入复用。**DockerBackend mounts/cwd（2026-09-23 容器化 M0）**：`run_once` 增 `mounts=[(宿主路径,容器路径)…]`（`-v` 宿主路径转正斜杠）与 `cwd`（`-w` 容器内工作目录）——sandbox 忽略两者（L3 零挂载铁律）。**已知局限**：WSL/Docker 杀的是客户端进程（wsl.exe/docker CLI），WSL 侧/容器内残留由 distro/容器生命周期兜底。**容器生命周期原语（2026-10-07）**：`run_once` **L2 分支补 `--rm`**（曾漏致每次 `run_cmd(runtime="docker")` 留一个 exited 容器、累积上千拖垮 Docker Desktop 仪表盘——`container-execution-architecture` §2 早记录的已知小坑）+ 可选 `name/labels`；新增 `run_detached`（`-d` 常驻、**绝不 `--rm`**）/`stop`/`start`/`restart`/`rm`/`inspect_running`/`ps_by_label`（只 `{{.Names}}` 做 format——`.Label "k"` 内嵌引号在 Windows 下易被 CLI 曲解，归属改由容器名编码），`exec_in` 扩 `cwd` |

## 约定与坑

- 不可信代码只允许 docker/sandbox；活体恶意样本必须 L3 + net=none/fakenet，**fakenet 尚未实现（NotImplementedError），malware 轨后置**。
- WSL 不是隔离边界：信任级与宿主同级，审批不可放松本条与 L3 硬底线。
- net=real 不默认、也不再需人工审批（2026-10-01 起 run_cmd 可直接指定）；隔离等级/threat_class 约束不变。
- 工具异常一律文本回填 Agent 循环（见 core/agent/CLAUDE.md）。
- 测试：tests 内 FakeDockerBackend 模式（断言 sandbox + net=none）；网关拒绝/降级用例在 tests/test_agent.py。
