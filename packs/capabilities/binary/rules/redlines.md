# 二进制能力包红线（永久强制，优先级最高）

> 状态：**草案（AI 起草 2026-09-16，待人审定稿）**。
> 适用于启用 binary 能力包的所有项目（全轨注入）；与任何 skill / 知识库冲突时以本文件为准。
> 轨级红线（如 research 的三层数据纪律）在此基础上叠加，两者冲突以更严者为准。

## 信任与执行

1. **样本默认 untrusted**：静态解析（strings/file/反汇编脚本读取/headless 反编译器）
   属可信**解析**，可走 host；任何**执行**样本（含调试器动态分析、运行 exploit 验证）
   必须经容器/sandbox 隔离，未知样本按恶意处理（断网优先，DESIGN.md §7）；
   不得为图方便标 trusted 绕过隔离。
2. **Pwn 打远程仅限授权靶机**：对远程服务的利用只允许题目环境/项目授权靶机；
   意外连通非目标服务立即断开并上报。

## 数据与证据

3. **反编译前先查 func_kb**：分析任何函数前必须 `bb_query what=func`（按 binary_sha256）
   看队友是否已分析过——重复劳动是硬违规；自己分析完立即 `bb_upsert_func` 落库。
4. **地址与证据绑定**：func_kb 结论必须带地址；findings 必须挂 binary 资产且 evidence
   带反编译片段/运行输出，无证据标 status=unverified。
5. **伪码不进事件流**：长伪码按需读缓存/落产物，不复制进事件或任务结论，避免淹没上下文。
