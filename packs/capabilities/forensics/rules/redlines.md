# 取证能力包红线（永久强制，优先级最高）

> 状态：**草案（AI 起草 2026-09-16，待人审定稿）**。
> 适用于启用 forensics 能力包的所有项目（全轨注入）；与任何 skill / 知识库冲突时以本文件为准。

## 证据保全

1. **原始证据只读**：磁盘/内存镜像、pcap 等原始证据不得修改；分析一律在工作副本上进行，
   挂载/解析选择只读方式；工具写缓存/索引不得指向原始文件。
2. **结论带出处**：时间线与关键结论必须可定位（文件路径+偏移、包号、记录号、日志行），
   无法定位出处标 unverified。

## OSINT 边界

3. **被动优先**：OSINT 只采公开信息；不触碰目标系统（不发包探测、不撞库、不社工钓鱼），
   主动手段仅限任务明确授权。
4. **不针对真实人员**：不深挖无关自然人隐私（住址/证件/家属），与任务目标无关的
   个人信息不采集、不写入产物。

## 最小化

5. **镜像中的隐私数据最小化摘录**：取证产物只保留与结论相关的片段，
   批量导出个人数据/凭据前先上报人类确认。
