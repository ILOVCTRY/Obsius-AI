## 5. Web 判级速查（影响「报上去定什么级」）

- **严重**：RCE / 任意代码执行 / 上传 webshell / SQLi 拿系统权限 / 缓冲区溢出；核心 DB（资金、身份、交易）SQLi 可拖大量身份/订单/银行卡；逻辑缺陷（任意账号资金消费、任意账号登录、任意密码修改）
- **高危**：一般服务器权限获取；非核心 DB SQLi、源码压缩包泄露、加密算法可逆/明文存储、移动 API 摘要、硬编码、**Github 泄露可登录重要服务器的账号密码**；绕过认证进后台、后台弱口令（见 §5 ①）、SSRF 捞大量内网敏感信息；越权敏感操作（改重要信息/订单越权/业务配置修改）；可自动传播且能拿认证 Cookie 的存储型 XSS
- **中危**：需交互方影响他人的存储型 XSS、重要 CSRF；普通越权（改用户资料）；Web/系统路径遍历、密码经 HTTP 明文传输（HeyTap 登录）；验证码逻辑缺陷被绕过撞库；重要账号体系无限制爆破
- **低危**：反射型 XSS / DOM-XSS、普通业务存储型 XSS；路径参数、SVN、phpinfo、日志、异常信息泄露、非 HeyTap 登录 HTTP 明文；OPPO URL 跳转（需证明跳非 OPPO 域且无提示才算）；Self-XSS、json hijacking、clickjacking+有效 exp、非重要敏感 CSRF、需 MITM 的 RCE+有效 poc；运维配置不当、组件权限漏洞；短信轰炸（单 IP/用户半小时定向 >50 条且无限制）
- **无危 / 不收**：功能 bug、乱码、样式混编、无意义目录遍历、兼容性问题；无法利用的扫描器报告；`http smuggling`（HTTP 请求夹带）；需用户交互的 CORS 拿 Cookie；无敏感信息的 json hijacking；内网 IP/域名泄露；无敏感操作 CSRF（购物车/点赞/评论）；中间件版本号；6 位验证码分布式爆破；其它危害过低

**Web 判级红线（特殊说明）：**
- ① 管理后台弱口令：进去**无**敏感信息/操作 → 最高只到**中危**；进的洞一般**降级**处理
- ② DoS 只收漏洞导致的那种；大流量高并发 DoS **不收**
- ③ 用 XSS / URL 重定向去打 App → **中危**起步
- ④ 最近披露的 0day 要等 **30 天冷静期**，且只收 OPPO 产品/服务自身

## 7. 敏感信息泄露定级（数量门槛，报数据规模有用）

| 级别 | 用户个人敏感信息（身份/金融/健康/位置/通讯录…） | 欧加集团员工信息（不含代理/供应商） |
|------|------|------|
| **严重** | 三元组 ≥100万 或 二元组 ≥300万条 | 三元组 ≥6万 或 二元组 ≥8万条 |
| **高危** | 三元组 ≥10万 或 二元组 ≥30万条 | 三元组 ≥3万 或 二元组 ≥5万条 |

- 其他按实际危害评；数量仅参考，随系统重要度/总量浮动
- 提醒：未授权读少量（收敛≤5组）走**越权中危**，别硬凑成敏感泄露去够严重线

## 8. 移动应用判级速查（ColorOS / realme UI / 软件商店自有 App）

- **严重**：远程 RCE / 远程或弱交互**静默装任意应用** / 远程账户接管·锁屏绕过·转账
- **高危**：本地 RCE；弱交互或本地敏感泄露（登录凭据/短信/通话/通讯录/浏览记录/App 私有目录）；本地提权；弱交互或本地账户接管等；浏览器 **UXSS**
- **中危**：MITM 的 RCE 或静默装（有效 poc）；IMEI/IMSI/手机号泄露；远程 DoS
- **低危**：MITM 敏感窃取（有效 poc）；有实际危害的 UI 欺骗
- **无危/不收**：功能缺陷、扫描器报告（又「无加固/反编译」）、业务需要配置的组件暴露（Activity export 无法利用）、**本地 DoS（仅本地发起致临时崩溃）**、无法重现
- 交互定义：**远程**=不碰手机网络触发；**本地**=要装恶意应用/adb/NFC/蓝牙；**弱交互**=诱导点链接即可；**强交互**=诱导装 app/钓鱼邮件/≥2次确认
