## 已验证路径

### wengine 网关 488「资源未对 IPv4 发布」= 悬空 vhost 死路判定
- 特征组合：HTTPS 全路径 488 / HTTP 全 301→HTTPS / 无 AAAA 记录
- 判定：该子域未对当前 IPv4 发布资源，属悬空 vhost，标记 na/死路，停止继续深挖
- 实测：zsw.zut.edu.cn → 202.196.32.120

### 主站业务流带出真实子域（与「前端 JS 挖真实入口」互补）
- 悬空 vhost 不直接放弃：回主站业务流提取真实业务入口链接
- 实测：zsw 死路 → 主站业务流带出真实招生网 zsc.zut.edu.cn（博达 VSB9，.138）

### 博达 VSB9 AOP formquery 招生季查询模板验证流程
- 模板形态：高考录取查询（needLogin=N / msgCode=N 无验证码，凭姓名+身份证精确匹配）+ 录取分数
- 注入/越权判定三板斧：data/get/info 是否强制全查询条件 → 引号注入是否响应无差异 → 是否存在模糊匹配
- 实测结论：强制全查询条件 + 注入无差异 + 无模糊匹配 → 无越权批量读/无 SQLi，按暴露面线索登记 intel（find-ddfb551d6304）

## 坑

1. 488 是网关对未发布 vhost 的显式响应，不是端口存活/服务故障信号；不要据此继续扫端口或当访问失败重试
2. 教育网招生查询在线模板常见「姓名+身份证精确匹配 + 无验证码」，不能直接定越权批量读；必须跑完 data/get/info 的注入差异验证再下结论
3. Spring Boot（actuator/WEB-INF）被自研 WAF 全 403 且绕过变体（大小写/编码/路径拼接）均 403 时，直接标记 tested_clean 收口，反复试绕过低回报（实测 zcps.zut.edu.cn）
