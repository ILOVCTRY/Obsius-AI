# 指纹 PoC 库（`skills/src-strike/poc/`）

与 `知识库/`（通用方法论）并列的 **已验证指纹级 PoC 沉淀库**。
挖到洞后，把「换一个资产大概率再遇到」的漏洞打法按**关键指纹**落地，下次进站命中同指纹直接复现，不用重打。

## 定位区别

| 库 | 内容 | 什么时候用 |
|----|------|-----------|
| `知识库/打穿短表.md` | 手法索引（认什么 → 打哪 → 出什么算成 → 假点） | 进站开场几枪 |
| `知识库/*-test.md` | 某一类漏洞的通用测试方法论 | 对得上类型，开对应模块 |
| `poc/<关键指纹>.md` | 某个指纹资产**已验证**的打法 + 可复制报文（纯报文，无脚本） | 进站命中同指纹，直接复现 |
| `poc/<关键指纹>/` | **需配套 py 脚本的指纹**：独立目录，`README.md`（报文本体）+ `.py` 脚本同夹 | 有自动复现需求时 |

一句话：短表教你怎么想、知识库教你这类怎么打、本库告诉你**打通过的那个实物**长什么样、报文长什么样。

## 命名与摆放（硬）

**两种形态，按「是否需配套 py 脚本」二选一：**

| 形态 | 适用 | 摆放 |
|------|------|------|
| **单文件** | 只存报文 + 打法，够复现 | `poc/<关键指纹>.md` |
| **独立目录** | 该指纹有可复用 py 脚本 | `poc/<关键指纹>/`：目录名=指纹名；内部 `README.md` 承载报文本体（同单文件结构）+ `.py` 脚本同夹 |

成目录的规则：**要放 py 脚本 → 一定要单独成一个目录，把该指纹 md 与 py 放同一个夹里**，不要 `.md` 平铺在根、`.py` 也平铺在根而互相失联。纯报文无脚本 → 单文件即可，不必建目录。

指纹名 = 命中就能判资产的**稳定特征**，做主名；漏洞点做后缀。

- 好例：`nacos-默认密钥-rce.md`、`solr-未授权-vm模板.md`、`xxl-job-未授权新建任务.md`、`spring-actuator-heapdump.md`、`minio-匿名列桶-改对象.md`、`超星慕课-课程媒体对象未授权读-任意下载/`（目录型）
- 用汉字短词 + 中划线，**不用空格/括号/斜杠/版本号当主名**（版本会漂，指纹不变）
- 一个指纹占一个文件/目录；不同指纹拆开；同一指纹多手法可合并

## 写入时机

中危/高危/严重**确认后**（过了 `vuln-report-format` 匿名闸/认钥闸），与正式报告**同时**落这里。判不判沉淀看**跨资产复用性**：

| 沉淀 | 不沉淀 |
|------|--------|
| 中间件 / 开源组件 / 框架 / 固件设备 / 固定版本 / 常见接口组合 | 业务定制逻辑（本站特有的跳转、换 id 规则）；只看一次就失效的配置错 |

判断不了先沉淀，写完没用再删。**此库是证据不是上限：表上没有的指纹照样挖。**

## 内容模板

每个**文件/目录内 README.md** 按下面结构写，首行注释块带识别特征方便 grep。
**目录型**（需 py 脚本）：`README.md` 用下面模板做报文本体；同目录放 `.py` 脚本，脚本头部注释也带指纹名与用法，脚本内占位符不存实值。
**单文件型**：就是没 py 的下面模板本身。

```markdown
# <关键指纹>

> 指纹：<一句话定义>。进站命中以下特征即开本文件。

## 一眼识别
- <1~3 条稳定特征：页面/接口/回包头/版本/JS 关键字，不靠猜>

## 已验证 PoC
```http
<原始 HTTP 报文，整体可复制；带 <HOST> 等占位符，不存实值>
```

**判据**：<什么回包/状态/后续口算成立；对照写一句>

## 替换点说明
| 占位 | 怎么拿 |
|------|--------|
| `<HOST>` | 目标地址 |

## 最小伤害证明
- <验证到哪一步为止：读到什么/改完即还原；延续「越权最小伤害」红线>

## 备注（可选）
- WAF 绕过 / 版本差异 / 修复后怎么识别
```

## 使用时机

进站抽 JS / 回包出指纹 → `grep -r poc/`（关键词：组件名、接口名、品牌名，目录型会整夹命中）→ 有对得上的直接打开复现 → 复现不成交叉看「一眼识别」确认是不是真同指纹。目录型：读内部 `README.md` 看报文，`*.py` 为自动复现脚本。没有命中 → 按知识库 / 自身能力正常打。

## 安全边界（硬）

1. **报文一律占位符**（`<HOST>` / `<SESSION>` / `<AK>`），**不存密钥/会话实值，不存 PII**（别人手机/身份证/正文）。
   密钥实值、完整 JS 只进正式报告（`rules/vuln-report-format`）。会话/令牌会过期，本库给的是**打法**不是当次证据。
2. PoC 只写验证路径与最小伤害证明：能读到数据就证明读到，不写批量枚举/直接破坏的放大步骤；改完即还原，禁止真资损。
3. 定级/判级/落不落只认 `vuln-report-format`，本库不另定级；与 `rules/` 冲突 → **以 rules 为准**。
4. 删废/合并按去摩擦原则（`skill-as-boost`）：保证真实、可复用、不重复，不借整理把能力写窄。
