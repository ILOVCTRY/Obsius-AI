# 高阶数学攻击

LWE/通用格建模见 [[crypto/格与后量子/lattice-and-lwe.md|格与 LWE]]；椭圆曲线专项见 [[crypto/非对称加密/ecc-attacks.md|椭圆曲线攻击]]；RSA 参数缺陷见 [[crypto/非对称加密/rsa-attacks.md|RSA 攻击]]。

## 0. 判据速查

| 观察 | 结论 | 动作 |
|---|---|---|
| 群阶或其素因子小 | 光滑阶 | Pohlig-Hellman + CRT |
| `g^x=a`，`x` 汉明重量低 | 稀疏指数 | 分段 BSGS |
| 方程有解且“接近”某值 | 小根 | Coppersmith |
| `h_i = f*p_i + 小噪声` | 近似 GCD | LLL |
| 公开扭点像（SIDH） | isogeny 参数 | Castryck-Decru，不要硬解 |
| 群律不是标准模乘 | 自定义群 | 找群阶与同态映射 |
| GF(2) 上线性关系 | 线性代数 | 高斯消元 |
| 解密 oracle 只有“合法/非法” | padding oracle | Manger 二分 |

## 1. 通用 DLP 工具

### 1.1 Pohlig-Hellman

若群阶 `n` 光滑，分解后在每个素数幂子群内用 BSGS 求解，再 CRT 合并。ECC 里对点运算同样适用：先 `factorint(#E)`，逐子群对点做 BSGS。阶是曲线本原参数的一部分；`#E == p`（异常曲线）应转 [[crypto/非对称加密/ecc-attacks.md|ECC 专项]]。

### 1.2 BSGS 与稀疏指数

标准 BSGS 复杂度 `O(√n)`。若指数 `x` 的汉明重量 ≤ k（如 128 位中仅 11 位为 1），按位分组建表：

```text
x = x1*2^64 + x2，x1、x2 各含少量置位
baby: 枚举所有低重量 x1，存 g^(x1*2^64)
giant: 检查 a*g^(-x2) 是否命中 baby 表
```

表大小约 `C(64,k)`，远小于 √n。恢复后校验汉明重量是否与题面一致。

## 2. 小根与格

### 2.1 Coppersmith（Howgrave-Graham）

模 `N` 有多项式 `f` 且已知存在小根 `|x| < X`：构造移位多项式格，LLL 归约后取短向量组合得到新多项式，其根即候选。三类常见设定：

- **已知 `p` 的形式**：`p = base + 10^k*x`，则 `x ≡ -base*(10^k)^{-1} (mod p)`，构造以 `x` 为根的多项式在模 `N` 下求小根。
- **私钥相近**：由 `e1*d1 ≡ e2*d2 ≡ 1 (mod φ)` 得 `d2-d1 ≡ (e1*e2)^{-1}(e1-e2) (mod p)`，对首一多项式 `f(x)=x-r` 求小根，再用 `gcd(f(x0), N)` 分解。
- **通用小根**：`f(x) ≡ 0 (mod N)`，根小于 `N^(1/d - ε)`。

参数（`m`、`t`、`X`、`beta`）决定成败；LLL 无结果时先检查缩放与根的实际上界，而非盲目加大维数。

### 2.2 近似 GCD

`h_i = f*p_i + n_i`，噪声 `|n_i|` 远小于因子。以 `q*I` 为基、辅以 `h_i` 构造格，短向量同时暴露 `p_i`，再由 `f = (h1-n1)/p1` 恢复。样本数要略多于未知数，噪声界必须真实可控。

### 2.3 Merkle-Hellman 背包

超递增背包被 LLL 直接破坏：格行左块放单位阵（记录选中项）、末列放重量、末行末列放 `-target`；归约后找末坐标为 0、其余为 0/1 的行。现代实现不会犯此错，题目出现即按 lattice 走。

## 3. 特殊群结构

### 3.1 Clock 群 `x²+y²=1 (mod p)`

群律 `(x1,y1)*(x2,y2) = (x1y2+y1x2, y1y2 - x1x2)`，单位元 `(0,1)`，逆元 `(-x,y)`，阶为 `p+1`（不是 `p-1`）。已知多个群上点时可从 `gcd(x²+y²-1)` 恢复 `p`，再分解 `p+1` 走 Pohlig-Hellman。ECDH/ECC 变体出现该群律时同样先恢复模数。

### 3.2 四元数 RSA

模 `n=pq` 的四元数环可用 4×4 矩阵表示乘法；密文是矩阵幂的首行。解法利用分量间的比例关系 `c1*a2 = c2*a1 (mod n)` 等，消去 `m` 后得 `A*p + B*q ≡ 0 (mod n)`，于是 `q|A, p|B`，分解 `n`。也可按其阶整除 `p²-1` 分别在 `p`、`q` 下解密再 CRT。核心是识别“结构被嵌入分量”这一弱点。

### 3.3 同源与 SIDH

若题面公开扭点像（torsion images）且是 SIDH 参数，最优解是 Castryck-Decru 类攻击（利用 `E0: y²=x³+6x²+x` 的已知自同态环与 Richelot/Kani glue），不是通用 isogeny 计算。识别点是 SIDH 参数 + 扭点信息；纯通用 isogeny 只在参数极小时可行（随机游走 + LCA 找路径）。

## 4. GF(2) 与多项式

### 4.1 CRC 自反映

CRC 在 GF(2) 上线性：`CRC(a xor b) = CRC(a) xor CRC(b)`。要求 `CRC(x) = hexascii(x)` 时，按“每个输入位翻转引起的 CRC 输出差”建矩阵，解 `CRC(x) xor x = 0` 的 GF(2) 线性系统。基线取全零输入，逐位计算差分 remainder 作为列向量，高斯消元求解。

### 4.2 GF(2) 多项式 CRT 与 S-box

- 多项式 CRT：在 `GF(2)[x]` 上按不可约因子分解后逐因子求解再合并；重因子情形需用导数判断。
- **非置换 S-box 碰撞**：S-box 不是双射时，不同输入可产生相同输出，直接找碰撞可构造等价状态/密钥，无需遍历密钥空间。逐输出统计原像个数，最小原像类的输入优先尝试。

## 5. 协议级缺陷

### 5.1 Manger padding oracle

只有“密文合法/非法”二值反馈时，Manger 攻击分两阶段：先找 `f1` 使 `k*f1` 越过阈值，确定 `k` 的区间 `(threshold/f1, threshold/(f1/2)]`，再二分缩小区间直至确定 `k`，然后逐位恢复明文。相比 Bleichenbacher 更快，适用于 OAEP/相关构造的错误反馈。

### 5.2 RSA 签名 bug 与仿射密码

- 若签名就是 `m^e mod n`，等于给了加密 oracle：可对目标消息“加密”后求 e 次根伪造；`e` 小且 `m^e < n` 时直接开方。
- 仿射密码模数非素数：在模的每个素因子域分别消元，再用 CRT 组合；`a` 与模不互素时需单独处理对应因子域。

## 6. 纪律

先问三个问题：群阶是否光滑？量是否足够小（指数/根/噪声）？结构是否退化（非双射、线性、可分解）？三者皆否定再考虑通用搜索。每种攻击都要在原始参数上验证（DLP 回代、根回代多项式、明文回代协议），并记录使用的假设与边界条件。
