# 非常规代数结构与密码体制

主流攻击面见 [[crypto/非对称加密/RSA 攻击判据手册.md|RSA 攻击]]、[[crypto/非对称加密/椭圆曲线攻击.md|椭圆曲线攻击]]、[[crypto/对称加密/分组密码、MAC 与 AEAD 攻击.md|现代分组密码]]、[[crypto/格与后量子/格与 LWE 攻击.md|格与 LWE]]。

## 0. 判据速查

| 现象 | 弱化假设 | 动作 |
|---|---|---|
| 给的是波形矩阵（`.trs`/`.npy`）+ 已知明文 | 实现泄漏功耗 | CPA/DPA，见 §6.5 |
|---|---|---|
| 同态加密 + 解密 oracle | 密文保留明文结构 | 倍增/加减逐位抽取 |
| 概率加密 +  oracle | 消息空间小 | 二分/因式分解密文 |
| 非交换/热带/矩阵群 | 有不变量把共享值推出 | 找同态不变量 |
| 签名方程是二次型 | 可因式分解或可组合 | Pollard 类伪造 |
| 阈值共享模数乘积结构 | 份额互素 | Asmuth-Bloom CRT |
| 定制 Feistel/ARX | 差分线性 | 反射差分/故障单比特 |
| 量子协议可双向注入 | MITM 侧 | 控基控值得双方密钥 |
| 单调函数部分输出 | 高位决定低位 | 逐位定值 |

## 1. 同态与概率加密 oracle

- **Paillier LSB oracle**：利用同态倍增 `Enc(2m)` 的奇偶性与 `Enc(m)` 的关联逐位判定明文；也可通过同态减法的“wrap”检测高位。
- **oracle 规模绕过**：当 oracle 只接受小密文时，把密文分解/重组为可通过验证的等价形式再查询。
- **GM 概率加密**：同一明文可多次采样且可由已有密文组合出新密文；组合后与 oracle 比对即得判定位，重复恢复完整密钥位。
- **同态加一/除二**：对密文的明文反复 `+1` 观察第 N 位何时溢出，再减回低位并除以 2，可逐位读出整个明文。
- **差分隐私噪声**：Laplace 噪声若可同一查询多次采样，用均值抵消噪声后恢复真值。

共同点：oracle 泄露的是“明文某一位/大小关系”，每 bit 一次查询，最后拼接。

## 2. 群结构弱化

- **辫群 DH**：Alexander 多项式在连接运算下相乘。公开值若给出乘法分解的可乘不变量，攻击者可用 `shared ∝ pub_A · pub_B` 的同态关系，在没有私钥的情况下推出共享秘密（标量乘法换成多项式乘法）。
- **热带半环**：`⊕=min/max, ⊗=+` 的残除运算在密钥空间小时可逐字符反推；`key = a⊓b` 的形式直接代数解。
- **ElGamal 平凡 DLP**：当底数 `B = p-1`（或落在小子群）时指数直接可解；先检查 `g` 的阶。
- **矩阵 ElGamal**：若矩阵可对角化/化为 Jordan 形，指数运算转为按特征值的标量幂，从超对角线反解指数。
- **Cayley-Purser**：密文矩阵与公共矩阵之间存在逐元素缩放关系，可直接相除恢复缩放因子并解密，无需私钥。
- **OSS 签名**：`x² + k·y² ≡ m (mod n)` 的二元二次型；对 `m1·m2` 可由两条已知签名组合出乘法同态签名（Pollard 伪造）。

## 3. 签名、阈值与助记词

- **Asmuth-Bloom**：份额 `s_i = m + t·p_i` 且 `p_i` 两两互素，`k` 份份额的子集模 `∏p_i` 超过阈值即可 CRT 恢复 `m`；验证份额对应素数。
- **Rabin 变体**：`N` 为多项式形式时先分解（如 `(r²+3)(r²+7)` 或 Fermat 邻近平方），再对四个根做 CRT 组合，用已知 padding/可读性筛正确候选。
- **BIP39 部分助记词**：缺失位用校验和与词表约束剪枝，按信息熵从低到高枚举补全。
- **ElGamal 通用重加密**：密文可盲化重组；若实现不校验群元素归属，可构造等价密文绕过验证。

## 4. 定制分组实现

- **ForkAES 反射差分**：结构上重复轮次形成差分特征；用标准 AES S-box 的 DDT 搜差分链，按线性层建模（Sage `BooleanPolynomialRing`/MILP），从若干选择明文恢复密钥。
- **ForkAES/GhostBlood 故障型 ARX**：旋转量被削弱（“faulty rotate”）时，固定单比特输入差分收集约 2¹⁶ 对，按差分线性化部分 ARX 后暴力对应密钥字节。
- **FPE Feistel**：域小、轮数少时按已知结构暴力半个轮密钥（16 位量级），从选择明文验证。
- **icosahedral 对称群**：群阶 120，把单字符探测结果建立查找表后逐字符解密，域小可全表。

## 5. 代数与序列恢复

- **LCG 周期检测**：输出无限时保存历史，检测循环起点与周期后用 `history[(i-start) % period]` 预测未来。
- **Vandermonde 多项式恢复**：`f(x)` 在若干点的值构成 Vandermonde 系统，`rref`/消元解系数；域为 `GF(p)` 时按模 `p` 消元。
- **Hamming 交织**：按交织参数（行/列）反交织后做纠错；维度未知时小范围暴力并按纠错成功率筛选。
- **单调函数部分输出**：输出关于输入单调且仅高位可见时，逐位固定常量位后按位置权从高到低搜索，需与目标的精度模型（如 Sage `RealField(N)`/mpmath dps）严格一致。

## 6. 量子协议

BB-84 类协议若允许中间人自由选择基和值，可始终用同一基（如 Z）向一方发送固定值（如 1），在另一方随机测量并记录；基协调后攻击者同时拥有与两方的密钥，通过限速“猜对次数”与子集校验操纵验证通过。防御要求认证信道与基/值不可任意指定。

## 6.5 侧信道：功耗与电磁分析（CPA/DPA）

**判据**：题目给的不是密文，而是**一堆波形数据**（`.trs` / `.npy` / `.csv` / `.mat`），
每个样本对应「某个已知明文输入下的加密过程」。这是**功耗分析**，不是密码分析。

**数据形态判据**：

| 文件/结构 | 含义 |
|---|---|
| `.trs`（ChipWhisperer 标准） | 头部有 `num_traces`/`num_samples`，数据是 `int16` 波形矩阵 |
| `traces.npy` + `plaintexts.npy` | 分别是波形矩阵 `(N, S)` 与明文 `(N, 16)` |
| CSV，每行一个样本 | 第一列常是明文，后面是采样点 |
| `ntraces / nsamples / dlen` 三个变量 | ChipWhisperer 抓包脚本的典型输出，`dlen=32` 说明是「16 字节明文 + 16 字节密文」 |

**CPA（相关功耗分析）的完整流程**，AES-128 首轮为例：

```python
import numpy as np

traces = np.load('traces.npy').astype(np.float64)   # (N, S)
pts    = np.load('plaintexts.npy')                  # (N, 16)

# 1. 标准化：每个采样点去均值、除标准差（必须做，否则直流偏置淹没信号）
traces = (traces - traces.mean(axis=0)) / (traces.std(axis=0) + 1e-12)

SBOX = [...]   # 标准 AES S-box

for byte in range(16):
    corr = np.zeros((256, traces.shape[1]))
    for kg in range(256):
        # 2. 猜测密钥字节 → 算 S-box 输出 → 用汉明重量/汉明距离建假设
        hypo = np.array([bin(SBOX[p[byte] ^ kg]).count('1') for p in pts])
        hypo = hypo - hypo.mean()
        # 3. 与每个采样点求相关系数
        corr[kg] = (hypo[:, None] * traces).mean(axis=0) / (hypo.std() + 1e-12)
    best = np.unravel_index(np.abs(corr).argmax(), corr.shape)
    print(byte, hex(best[0]), '|corr| =', abs(corr[best]))
```

**判据（怎么确认猜对了）**：

| 现象 | 结论 |
|---|---|
| 某个 `kg` 的相关系数**显著高于其余 255 个**（通常 >0.3，其余 <0.1） | 猜对了 |
| 256 个相关系数**全部接近 0** | 采样窗口没对齐，或假设模型错了 |
| 相关系数最高点在**波形最左/最右边界** | 采样窗口截断了，扩大范围重抓 |
| 每个字节的最强相关点**位置逐渐右移** | 正常——AES 的 16 字节是顺序处理的 |

**DPA（差分功耗分析）**：不要求线性模型，把样本按假设位分两组，比两组均值之差。
CPA 更省样本、更鲁棒，**优先 CPA**；只有 S-box 输出与功耗关系非线性（如加了掩码）时才用 DPA。

**汉明重量 vs 汉明距离**：

- 不知道上一状态 → 用**汉明重量** `HW(SBOX(p^k))`
- 知道寄存器初值（如全 0）→ 用**汉明距离** `HD(prev, cur)`，信号更强

**RSA 的功耗分析**：判据是「一次模幂的波形里有两种明显不同的段」。
平方-乘法实现里，「乘」比「平方」耗电多，按段分类即得私钥的每个 bit：

```text
段长 ~200 采样点，5 针脚/高峰 = 1（做了乘法），3 针脚 = 0（只平方）
私钥 bit 序列直接读出来
```

**常见失败原因（按频率排序）**：

1. **没做标准化** —— 直流偏置让所有相关系数都接近 1，无法区分
2. **采样窗口错位** —— 只看 `traces[:, :100]` 但信号在 500 之后
3. **明文顺序错** —— AES 的 state 是列优先，`plaintexts` 若是行优先要转置
4. **样本太少** —— 少于 500 条时噪声占优，至少要几千条
5. **模型错** —— 以为是首轮实际是末轮，改 `SBOX[p^kg]` 为 `SBOX[ct^kg]`

**掩码/隐藏的判据**：CPA 完全无峰且样本量足够 → 实现加了掩码（一阶 CPA 失效），
需要二阶 CPA（对同一采样窗口的平方做相关）或改用模板攻击。

**同族：时间侧信道**（T-table 缓存命中）见 [[crypto/对称加密/分组密码、MAC 与 AEAD 攻击.md|现代分组密码]] §3.2。
判据区别：**给的是时间戳而不是波形** → 时间侧信道；**给的是波形矩阵** → 功耗侧信道。

## 7. 纪律

非常规体制先证明它“等价于某个已知弱结构”：同态→逐位 oracle；群→不变量/同态；定制实现→差分线性；协议→可 MITM。每步在原始题目参数上验证（解密回代、签名验证、明文可读），并记录所依赖的结构假设。
