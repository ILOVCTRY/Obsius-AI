# 椭圆曲线攻击

RSA、DSA 数学见 [[crypto/非对称加密/rsa-attacks.md|RSA 攻击]]；DH 与协议交互见 [[crypto/非对称加密/dh-attacks.md|DH 攻击]]；nonce 截断后的格攻击完整版见 [[crypto/格与后量子/lattice-and-lwe.md|格与 LWE]]。

## 0. 判据速查

| 现象 | 优先方向 | 关键动作 |
|---|---|---|
| 曲线参数可疑（阶小、`4a³+27b²≡0`、阶 `==p`） | 曲线级攻击 | 先算阶与判别式 |
| 服务端接受自定义点且不校验 | 无效曲线 | `b' = y²-x³-ax`，小阶子群 + CRT |
| x-only/蒙哥马利阶梯 | twist | 检查 twist 阶光滑性 |
| 两条以上公钥共享素因子 | 模数 GCD | 两两 gcd |
| 两条签名 `r` 相同 | nonce 复用 | 直接解 `k` 与私钥 |
| nonce 被截断/偏置 | HNP 格 | 走 lattice 篇流程 |
| 两次签名 `k` 相同且可构造 | MD5 碰撞 | 可控前缀碰撞生成同 `k` |
| ECDH 输出全零 | 低阶点 | RFC 7748 检查 |

## 1. 曲线参数体检（第一步）

拿到 `p,a,b,G,Q` 后立即检查：

1. **判别式** `Δ = -16(4a³ + 27b²) mod p`：为 0 即奇点曲线，ECDLP 退化为加法群（尖点）或乘法群（节点），多项式时间可解。节点情形可经平移把奇点移到原点后用映射 `(x→(x-r)/y)` 归约到 `GF(p)^*` 的离散对数。
2. **阶 `#E == p`**：异常曲线，Smart 攻击用 p-adic/Hensel 提升 `O(1)` 求解。这是最容易被忽略的捷径，永远先查。
3. **阶是否光滑**：`#E` 或扭曲线阶 `p+1-#E` 的最大素因子小，直接 Pohlig-Hellman。
4. **生成元是否在曲线上**：题面公布的曲线方程与 `G` 不匹配（ Fake generator）时，实际曲线参数应按 `b' = Gy² - Gx³ - a·Gx` 重算，再在真实曲线上解 ECDLP。
5. **嵌入度**：`mov_threshold` 小（≤6）时可用配对环境归约到 `GF(p^k)` 的 DLP。
6. **`a = -3/-4`**：可能存在 CM/GLV 内建自同态泄漏，配合签名结构恢复标量。

## 2. 无效曲线攻击（无点校验时）

短 Weierstrass 的加法公式只依赖 `a`，不依赖 `b`。若服务端不校验 `y² == x³+ax+b`，任意提交点都可解释为另一条曲线 `E_{a,b'}` 上的点，其中 `b' = y² - x³ - a·x mod p`。

攻击流程：

1. 选取/挖掘 `b'` 使 `#E_{a,b'}` 光滑或含小素因子 `r`。
2. 在 `E_{a,b'}` 上构造 `r` 阶点：随机点乘 `N/r` 后验证阶恰为 `r`。
3. 把该点提交给 oracle（返回 `[s]P`、MAC 或仅 x 坐标），得到 `s mod r`（x-only 时需尝试 `±`）。
4. 对多个互素的 `r_i` 重复，CRT 组合恢复完整 `s`。

变体要点：

- `a=-3`（P-256 优化）时可寻找阶含 `3·q` 的 `b'`，用三模数 CRT 解决符号歧义。
- 协议若返回 `C2 - d·C1`，直接令 `C1=-P, C2=O` 即得 `dP`；再选奇点曲线上的 `P=(1,1)`（`y²=x³`）可得 `dP=(d²,d³)`，于是 `d = y/x`。
- 只给 x 坐标（Montgomery ladder）时，`u` 可能落在 twist 上；twist 阶光滑即可从小阶点泄漏 `s mod r`。缓解（twist-secure、残留检查）失效时这条路径成立。

判定顺序：`is_on_curve` 是否缺失 → 公式是否用到 `b` → twist 阶是否光滑 → `Δ==0`？→ `G` 是否满足方程。

## 3. 非标量侧的实现缺陷

- **共享模数因子**：多份 ECC/DSA 公钥的两两 GCD 可能直接给出公共素因子，分解后各自解私钥。
- **故障注入**：对已知正确签名/计算翻转标量某位，比较输出是否变化可作为该 key 位的区分器；多次探测可逐位恢复。此方法只在授权实验环境用于验证实现缺陷。
- **侧信泄漏**：签名时间、缓存或错误信息可能暴露 nonce/标量位；有 `sign(uid, 2^t)` 这类可查询接口时，可通过倍增一致性逐位重建主密钥。

## 4. 签名协议层泄漏

### 4.1 nonce 复用

ECDSA/DSA/Ed25519 中两条签名 `r` 相同即 `k` 相同：

```text
k = (h1 - h2) / (s1 - s2) mod n
d = (s1*k - h1) / r mod n
```

恢复 `d` 后可伪造任意消息签名。Ed25519 同理按 `S = r + k·H(R,A,M)` 求解。

### 4.2 截断/偏置 nonce → HNP

若每次泄漏 `k` 的高位（或 `k` 取自小区间/带谓词），写 `k_i = leaked_i·2^t + delta_i`，代入 `s_i·k_i - h_i ≡ r_i·d` 得 `r_i·d - s_i·delta_i ≡ s_i·leaked_i·2^t - h_i`，按格攻击构造 lattice，LLL 后校验并补偿末尾少量位。签名数量、泄漏位数与维度共同决定成功率。

### 4.3 可控 `k` 生成

若 `k` 由带可控前缀的哈希生成（如 `k = int(MD5("K = {n: " + counter + ...))`），可用 MD5 快速碰撞生成两个不同 counter 得到同一 `k`，制造 nonce 复用。先验证服务端确实如此生成，再构造碰撞对。

### 4.4 小范围暴力

`k` 被限制在极小区间（如已知前导位）时，直接枚举并结合签名验证筛选，往往比建格更快。

## 5. ECDH 与 X25519/Ed25519 特有问题

### 5.1 低阶点与全零输出

X25519 必须校验输入不是低阶点，否则共享密钥可被预测（贡献性攻击失效）。`u=0` 与 `u=1` 恒为小阶；完整低阶集合共 8 个（阶整除 8）。判定方法：对两个独立 clamped 标量的输出是否全零（RFC 7748 的 all-zero 检查）。实现若省略该检查，服务端可能把攻击者的低阶点当成合法公钥。

### 5.2 Ed25519 扭点侧信

利用 `sign(uid, 2^t)` 这类接口检查 `S_t` 与 `S_{t+1}` 的倍增关系，可逐位重建主密钥（`MASTER_KEY ≈ l·(0.bit0 bit1 …)`），最后遍历少量扭点修正。修复要求对内部接口做同样的校验与访问控制。

### 5.3 特殊曲线的 DLP

- **Edwards/clock 曲线**：`p` 整除 `x²+y²-1` 时可恢复模数 `p`，再分解 `p+1` 走 Pohlig-Hellman。
- 若群阶光滑，无论曲线形式如何，优先 Pohlig-Hellman + CRT。

## 6. 纪律

ECC 题的代价排序永远是：查阶/判别式/twist/生成元 → 查校验缺失 → 查协议 nonce/随机源 → 最后才考虑通用 ECDLP。每步用已知 `(G, Q, k)` 三元组或签名验证回代；报告需写清曲线方程、校验缺口位置与修复建议（点校验、twist 安全、nonce 唯一性、低阶点检查），而不只是给出密钥。
