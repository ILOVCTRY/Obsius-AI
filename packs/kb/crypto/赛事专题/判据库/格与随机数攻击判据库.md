# 格与随机数攻击判据库

> 来源：约 40 篇格与随机数赛题 WP 的提炼（200+ 条观测）。原始 WP 已消化完毕并从库中移除，仅保留本节判据。
> 主库 `crypto/格与后量子/` 已有 LLL 基础，本文补**具体矩阵构造**与**参数选择判据**。

## 0. 判据速查

| 现象 | 判据 | 去哪节 |
|---|---|---|
| 有 `k` 个方程，未知数比方程多 | 格攻击（HNP） | §1 |
| 已知 `d` 的高位（部分位） | HNP / CVP | §1.2 |
| 子集和 / 背包 | 密度 < 0.94 可格解 | §2 |
| 共模 + 小未知数 | 格上求短向量 | §3 |
| CRC 需要逆向 | GF(2) 上仿射矩阵求逆 | §4 |
| 给了 MT19937 的 624 个输出 | 直接还原 state | §5.1 |
| 给了部分位 / 低位 | GF(2) 上 LLL | §5.2 |
| ECDSA 的 `k` 有偏 | HNP | §6.1 |
| 曲线参数不标准 | 先验曲线是否奇异 | §6.2 |

## 1. 隐藏数问题（HNP）

**判据**：有 `t_i = (a_i * x + b_i) mod n` 形式的方程，`x` 未知但比 `n` 小。

### 1.1 标准构造

```python
# 已知：a_i, t_i, n；未知：x（|x| < 2^k，k 远小于 log2(n)）
# 构造格：
# [ n   0   0 ... 0   0 ]
# [ 0   n   0 ... 0   0 ]
# [ ...                  ]
# [ a1  a2  a3 ... at 1/B ]   ← 最后一行
# 目标：找短向量 (t1 - a1*x, ..., tt - at*x, x/B)
```

判据是**未知数比约束多一个**。方程数 `t` 要满足 `t > log2(n) / k`。

### 1.2 参数选择

```text
scale = 2^k        # k 是 x 的位数
如果 scale 太大 → 格基数值溢出，LLL 慢
如果 scale 太小 → 短向量不唯一
经验值：scale ≈ 2^(k)，矩阵规模 t+1 维
```

**关键判据**：矩阵维数 = 方程数 + 1。维数超过 40 时 LLL 会很慢，改用 BKZ（`block_size=20~30`）。

### 1.3 失效条件

```text
x 的位数 > n 位数的一半  → HNP 不成立
方程数 t < 2              → 约束不足
a_i 有公因子              → 先约掉
```

## 2. 子集和 / 背包

**判据**：给一个序列和一个目标和，要求选子集。

```text
密度 d = n / log2(max(a_i))
d < 0.9408  → 格攻击可解（Lagarias-Odlyzko）
d > 0.9408  → 需要更复杂的方法，通常题目会给超递增序列
```

### 2.1 超递增序列（贪心）

```python
# a_i > sum(a_1..a_{i-1})
# 从大到小贪心：能减就减
for x in reversed(a):
    if s >= x: s -= x; bits.append(1)
    else: bits.append(0)
```

判据是**每个元素大于前面所有元素之和**。这是 Merkle-Hellman 的原始形态。

### 2.2 格构造

```python
# 矩阵：
# [ 1  0 ... 0  a1 ]
# [ 0  1 ... 0  a2 ]
# [ ...            ]
# [ 0  0 ... 1  an ]
# [ 0  0 ... 0  S  ]   ← S 是目标和
# 找短向量 (x1, ..., xn, 0) 其中 xi ∈ {0,1}
```

## 3. 共模与小未知数

**判据**：`c_i = (a_i * x + b_i) mod n`，多个 `i`，`x` 小。

这和 HNP 同构，区别是 `a_i` 常是 `e` 的幂（RSA 低指数）。

```python
# Hastad 广播的格版本（密文数 < e 时用）
# 构造多项式 f(x) = (m + x)^e - c mod n
# Coppersmith 找小根
```

判据是**密文数不够 `e` 个**。够了就直接 CRT，不用格。

## 4. CRC 逆向

**判据**：给了 CRC 值和部分消息，要求补全。

```python
# CRC 是 GF(2) 上的仿射变换：crc = M * data + C
# 求 M 的逆（GF(2) 矩阵求逆）
from sage.all import matrix, GF
M = matrix(GF(2), affine_matrix)   # 由多个已知 (data, crc) 对构造
M_inv = M.inverse()
```

判据是**CRC 的参数（多项式、初值、是否反射）已知**。未知时要先爆破参数。

**关键**：CRC 的线性性意味着「改一个 bit 对 CRC 的影响」是固定的，可以预先算好影响表。

## 5. 伪随机数

### 5.1 MT19937

```text
624 个连续 32-bit 输出 → 直接还原 state（untemper）
< 624 个输出           → 需要额外信息（种子范围 / 部分位）
种子是 32-bit 整数     → 枚举 2^32 太重，先试小范围
种子是 time()          → 按时间窗口枚举（前后几分钟）
```

```python
# untemper 四个步骤的逆
def unshift_right_xor(y, shift):
    x = y
    for _ in range(5):
        x = y ^ (x >> shift)
    return x
# 完整实现用 randcrack 库最省事
from randcrack import RandCrack
rc = RandCrack()
for v in outputs: rc.submit(v)
```

判据是**输出个数**。`randcrack` 需要 624 个连续输出。

**坑**：如果输出经过 `% 100` 之类的截断，`randcrack` 不能直接用，要走 GF(2) 上 LLL。

### 5.2 部分位泄露

```text
只给了输出的低 8 位 / 高 8 位
→ 每次输出提供 8 bit 线性约束
→ 624 * 32 / 8 = 2496 个输出可还原
→ 构造 GF(2) 上的线性方程组，用 LLL 或直接高斯消元
```

判据是**泄露的位数 × 输出个数 ≥ 19968 bit**（624×32）。

### 5.3 LCG

```text
x_{n+1} = (a * x_n + c) mod m
给了连续输出 → 解 a, c, m
```

```python
# 三个连续输出即可：
# x2 - x1 = a*(x1 - x0) mod m
# 用差分构造，gcd 求 m
d1 = x2 - x1; d2 = x3 - x2; d3 = x4 - x3
m = gcd(d2*d2 - d1*d3, d3*d3 - d2*d4)  # 多个差分求 gcd
a = (d2 * inverse(d1, m)) % m
c = (x2 - a*x1) % m
```

判据是**给了至少 4 个连续输出**。少于 4 个时 `m` 求不出来。

## 6. 椭圆曲线

### 6.1 ECDSA 的 `k` 有偏

```text
k 的高位已知 / k 的低位为 0 / k 落在小区间
→ HNP，用 LLL 恢复 d
```

判据是**签名样本数 ≥ 需要的约束数**。`k` 泄露 8 bit 时，约 20 个签名够。

**坑**：`k` 完全随机且不泄露时，ECDSA 是不可破的。不要在这上面耗。

### 6.2 曲线异常

| 异常 | 攻击 |
|---|---|
| `p` 不是素数 | 中国剩余定理分解 |
| 曲线奇异（判别式 = 0） | 映射到加法群/乘法群 |
| `#E` 光滑 | Pohlig-Hellman |
| `#E = p` | Smart 攻击（p-adic） |
| `p` 很小（< 2^40） | 直接暴力 `d` |

判据是**曲线的参数不是标准曲线**（不是 secp256k1/P-256 等）。自定义曲线必查异常。

```python
# 查阶是否光滑
E = EllipticCurve(GF(p), [a, b])
print(E.order().factor())
```

### 6.3 已知 nonce

```python
d = (s*k - h) * inverse(r, n) % n
```

判据是**给了 `k`**。这是最直接的，不要绕。

## 7. 对称密码的结构弱点

| 弱点 | 判据 | 攻击 |
|---|---|---|
| 固定 IV + 固定 key | 两次加密同明文得同密文 | 重放 / 差分 |
| CTR 重用 nonce | `c1 ^ c2 = m1 ^ m2` | 已知明文恢复 |
| CBC 可预测 IV | 第一块可控 | 字节翻转 |
| ECB | 相同明文块得相同密文块 | 块重排 |
| 密钥派生可逆 | `key = f(known)` | 直接算 |

判据是**模式与 IV 的管理方式**。CTR 重用 nonce 是最高频的洞。

## 8. 纪律

- **先判「能不能写成线性组合」**。不能就不该用格。
- **格维数超过 40 换 BKZ**，LLL 会慢到不可用。
- **`scale` 参数是调出来的**，不是算出来的。多试几个值。
- **MT19937 要 624 个连续输出**，不够就走部分位路线。
- **LCG 要 4 个连续输出**才能求 `m`。
- **自定义曲线先查阶是否光滑**，这是最高频的洞。
- **`k` 完全随机时 ECDSA 不可破**，别浪费轮次。
- **本地用小参数验证格构造**，再上真实规模。构造错了在真实规模下只会表现为「LLL 出来的向量没意义」，很难 debug。
