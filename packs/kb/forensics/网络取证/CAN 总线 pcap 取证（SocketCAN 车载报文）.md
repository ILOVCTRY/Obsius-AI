# CAN 总线 pcap 取证（SocketCAN 车载报文）

车载/工控总线场景（底盘动力域、OBD-II、vcan0 回环）没有五元组、没有会话、没有 TCP 流可 follow，
判据必须换成**仲裁 ID + 周期网格 + 物理量平滑性**。通用 IP 流量方法见
[[forensics/网络取证/网络流量取证与协议隐写.md|网络流量取证]]。

纪律：先确认封装与字段名再谈解码；锁定信号要给可量化判据而不是"看起来像车速"；
剥离干扰要给出锁相率与时钟 RMS 数字；报告位置必须同时写清口径。

## 测试面

| # | 方向 | 判据（怎么发现） | 动作 |
|---|---|---|---|
| 1 | 封装与字段确认 | `-z io,phs` 只有 `data` 没有 IP 栈；`-V` 报 SocketCAN | 认双口径 linktype，改用 `data.data` 取载荷 |
| 2 | 物理量信号锁定 | 几十个 ID 中只有一个唯一值数高一个数量级 | 算 uniq + 包络变向次数 + 二阶差分 |
| 3 | 伪造节点剥离 | 某 ID 帧数不是标称周期的整数倍 | 算总线网格锁相率与时钟 RMS |
| 4 | 峰值定位与口径 | 已锁定单条分段单调曲线，要求报告"位置" | 列全四种口径，按答案格式选 |
| 5 | 隐藏通道扫描 | 描述里没有物理量语义，或 §2 无候选 | 位平面 / 元数据 / 时序通道穷举 |

## 1. 封装与字段确认：判据与步骤

**判据**：`file` 报 pcapng；`tshark -q -z io,phs` 分层统计里只有 `data`，没有 IP/TCP/UDP；
`tshark -V | head` 的 Encapsulation type 报 SocketCAN。

**动作步骤**：

```bash
file capture.pcapng
capinfos -c -u -M capture.pcapng            # 帧数 + 时长，作为后面找异常节点的基线
tshark -r capture.pcapng -V | head -40      # Encapsulation type
tshark -r capture.pcapng -q -z io,phs       # 协议分层
tshark -G fields | grep -i can              # 字段名探测
```

- **linktype 227（DLT_CAN_SOCKETCAN）与 `-V` 里的 `Encapsulation type: SocketCAN (125)`
  是同一封装的两套编号**（DLT 号 vs WTAP 封装号）。看到两个不同数字不要当成两种格式写两份解析器。
- 载荷字段是 `data.data`，**不是 `can.payload`**——后者在多数 tshark 版本不存在且
  **静默返回 0 行**，不报错，极易被误判成"这个 ID 没有数据"。先 `-e data.data` 确认有值，再回头找语义字段名。
- `can.id` 输出是**十进制**。过滤器里 `can.id == 0x1A0` 与 `can.id == 416` 等价，比对前先换算。
- 接口名为 `vcan0` 说明是 Linux 虚拟 CAN 回环，数据多为合成或重放，不必找真实车辆特征。

**不成立**：若 `-z io,phs` 出现完整 IP 栈、或存在可 follow 的 TCP 流，按普通流量取证走，
不要套本篇——CAN 场景的前提是二层之上没有 IP。

## 2. 物理量信号锁定的适用条件与步骤

**适用条件**：几十个仲裁 ID 中，**只有一个的唯一值数比其余高一个数量级**，且包络变向次数极少
（典型为先升后降的抛物线）；其余多为 4 / 8 / 64 态循环计数器或全零常量。

**动作步骤**：按四个指标一轮筛完，不要逐个肉眼翻 payload。

| 指标 | 计算 | 真信号 | 计数器/干扰 |
|---|---|---|---|
| 唯一值数 | `len(set(payload))` | 高一个数量级（数百） | 极低（4/8/64 态） |
| 包络变向次数 | 相邻差分符号翻转次数 | 极少（个位数） | 与帧数同阶 |
| 二阶差分平滑度 | `mean(abs(d2V))` | 远小于 1 LSB | 大或呈锯齿 |
| 与时间 / 帧序号拟合 | 分别做线性回归残差 | **按帧序号推进时残差小** | 按时间拟合残差大 |

最后一行是关键判据：**数值按帧推进、时间戳才是抖动源**时，V~帧序号残差会明显小于 V~时间残差；
若反过来，说明信号与墙钟绑定，考虑是不是测速以外的量。

```python
for cid, rows in by_id.items():
    vals = [int.from_bytes(r[3:5], 'big') for r in rows]      # 位域先扫多组再定
    uniq  = len(set(vals))
    d     = [b - a for a, b in zip(vals, vals[1:])]
    turns = sum(1 for a, b in zip(d, d[1:]) if a * b < 0)
    d2    = sum(abs(x - 2*y + z) for x, y, z in zip(vals, vals[1:], vals[2:])) / max(1, len(vals) - 2)
```

位域不要只试 `u16be@0`：12-bit / 10-bit 跨字节位域、16-bit 补码、单字节有符号都要扫一遍。
前几字节恒零的短帧，有效量常在尾部两字节。`u16le` 会给出杂乱值，用"是否分段单调"反推字节序。

**不成立**：若所有 ID 的唯一值数都在同一量级（都是计数器、或都是模拟量），
说明这不是"找唯一物理量"型任务，转 §5。

## 3. 伪造节点剥离：常见坑与证伪步骤

**判据**：某 ID 的帧数不是标称周期的整数倍；相邻帧间隔直方图呈双峰（如 10ms 与 16ms 并存）；
描述里出现「剥离干扰数据」「Rogue Beacon」「数据中断」这类措辞。

**动作步骤**：取所有合法 ID 的 Δt 众数作为标称周期 P，对每个 ID 拟合 `t_k = t0 + k*P`，
算残差 RMS 与 `|残差| < 0.5*P` 的占比（锁相率）。

- 合法 ECU：锁相率 **50% 以上**，时钟 RMS **小于 1 ms**。
- 注入/伪造节点：锁相率 **低于 30%**，时钟 RMS **大于 5 ms**（软件定时器驱动，几乎必然脱网）。

**常见坑**：不要把 Δt 双峰直接读成"两个节点各发一条链、一条真一条假"。用**数值阶梯**证伪：
若真是两条独立信号交织，合并后相邻两帧必然出现重复值或跳变（dV = 0）；
若合并后 dV 恒为同一常数、异常步数为 0，说明**数值层只有一条链**，
所谓干扰只在时间戳层（到达时刻被打乱或重放），峰值判定不受影响。
辅助判据：约束双链时钟拟合的最佳周期若给出 RMS 远差于合法 ID，即可判定"两节点模型不成立"。

**不成立**：若所有 ID 锁相率都在同一水平且 RMS 都小于 1ms，说明没有注入节点；
此时"干扰"只可能是某个 ID 的**假信号**，回 §2 复查候选物理量而不是继续拆时间。

## 4. 峰值定位的复现步骤与口径

**适用条件**：已锁定单条分段单调曲线（先升后降或含换挡下凹），要求报告"峰值发生的确切位置"。

**动作步骤**：先把四种口径列全，再按答案格式选，不要混报。

| 口径 | 取值方式 |
|---|---|
| 全局帧号 | Wireshark 的 `frame.number`（1-based 全局序号） |
| 时间戳 | 绝对 epoch / 相对首帧偏移 |
| 候选 ID 流内序号 | 过滤后重新计数，0 起与 1 起都要算 |
| 容器字节偏移 | pcapng 块偏移 / 载荷偏移 |

- 默认取全局帧号：这是状态栏与 `-e frame.number` 的原生语义，描述里说的"数据包的序号"通常指它。
- 流内序号与全局序号会差一个数量级（单个 ID 帧数远少于总帧数），两者都算出来备用但不要混报。
- **峰值唯一性必须复核**：排序取前若干，确认最大值只出现 1 次、次高值出现 2 次以上；
  峰值两侧对称说明是斜坡顶点而非孤立尖峰。
- 换挡或起步下探造成的局部凹陷不是假峰：只要它比全局峰值低一个量级、且峰值落在其后上升段末端，直接排除。
- 哈希型 flag（`flag{SHA256(位置)}`）：对**十进制字符串**算摘要，用 `printf` 而非 `echo`
  （后者追加换行，摘要直接错），并用 `xxd` 确认输入无尾随空白。

**不成立**：若最大值出现多次（平台期），说明这个 ID 不是连续模拟量或存在多路交织，回 §3 拆流；
若曲线没有分段单调结构，回 §2 重选候选。

## 5. 隐藏通道穷举：适用条件与判定

**适用条件**：描述里只给"找 flag"、没有物理量语义；或 §2 找不到唯一模拟量。

**动作步骤**：按成本从低到高穷举，每层都要报"扫了多少组、命中多少"。

- **容器结构**：pcapng 是否有多个 SHB、是否存在非 SHB/IDB/EPB/ISB/NRB 的自定义块、
  解析结束偏移是否等于文件大小（尾部附加数据）、EPB option 区长度是否恒 0。
- **元数据**：SHB/IDB/ISB 的 option（comment、if_name、custom），压缩包 EOCD comment 与 extra field。
- **位平面**：每个 ID × 每字节 × 每 bit（含取反）× 8/7/6/5 位打包 × msb/lsb × 全偏移。
- **时序**：时间戳低位、Δt 残差低位、帧间隔符号，转 ASCII。
- **状态编码**：多态计数器的状态序号 → 索引 / bit / base64 三路解码。

**不成立**：穷举零命中**本身是有效结论**——据此可判定答案是"位置或数值"而非 flag 字符串，
转 §4 出位置。不要把"没找到 flag"写成"没找到隐藏数据"，两者含义不同。
