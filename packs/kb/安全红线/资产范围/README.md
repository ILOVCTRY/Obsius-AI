# 资产范围（asset scope）

> **这是什么**：给 Agent 与 FOFA 查询用的**机器可读**资产范围。人读的授权条款/无害化边界在
> `安全红线/平台规则/<tag>.md`，本目录只管「哪些资产算这个平台的、怎么用测绘引擎圈出来」。
>
> **谁消费**：`core/asset_scope.py`（`intel_assets` / `fofa_search` 工具的入参约束与结果过滤）。
> 改这里的格式等于改工具行为——新增平台时**复制一份改内容**，不要改动本文件的结构。

## 文件命名

`<tag>.md`，tag 与 `平台规则/<tag>.md`、`评级与价值口径/<tag>.md` **同名**（`edusrc` / `osrc` / `ysrc`）。
同名是为了让三份文件一眼对上：授权边界、判级口径、资产范围各一份。

## 每行一个条目（三种写法）

文件正文按行解析，**空行与 `#` 开头的行跳过**。每行三种形态，按前缀区分：

| 写法 | 示例 | 含义 |
|---|---|---|
| 域名/通配 | `*.edu.cn` | 域名后缀匹配（含裸域 `edu.cn` 本身） |
| IP / CIDR | `10.0.0.0/8` | 网段匹配 |
| FOFA 片段 | `fofa: org="China Education and Research Network Center"` | 追加到查询语句的**限定片段** |
| 文字说明 | `说明: 教育资产不一定以 edu.cn 结尾` | 只给人看，解析器忽略 |

要点：

- **`fofa:` 行是查询侧约束**（用来圈出候选资产），**域名/IP 行是结果侧校验**（用来剔除误命中）。
  两者都不必写——只写 `fofa:` 就只能靠查询语句兜住范围，只写域名就只能过滤已有结果。
- 域名行**不写 `fofa:` 前缀**：解析器按「含 `/` 或像 IP → CIDR；含 `.` → 域名」自动归类。
- 一行只写一个值，不要用逗号分隔多个（逗号是 FOFA 语法的一部分，解析器不切分）。
- 中文说明行统一用 `说明:` 开头，避免被误判成域名。

## 与 `平台规则/*.md` 的关系

- 授权依据、无害化边界、提报格式 → **仍以 `平台规则/<tag>.md` 为准**，本目录不重复。
- 本目录写错了会**放宽**资产收集范围（把不属于该平台的资产圈进来），所以宁可少写不可多写；
  拿不准的域名先不写，让 Agent 在结果里显式确认。
