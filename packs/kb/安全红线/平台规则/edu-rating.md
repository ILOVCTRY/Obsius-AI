# 教育行业资产评级配套规则（与 `评级与价值口径/edu-rating.md` 配套）

> **触发：** 目标属于教育行业资产（`.edu.cn` 及各级学校/高校域名、各省教育厅/人社局、中科院体系单位）时生效。本文件管「能不能打、怎么证明」，判级条款见 `评级与价值口径/edu-rating.md`。
>
> **授权依据正本**：`平台规则/edusrc.md`（EDUSRC 规则页 `https://src.sjtu.edu.cn/introduction/`，2026-09-08 核验）。本文件是它的评级配套指针，不复制授权条款。

## 与授权规则的关系

- **授权边界 / 无害化三原则**（机密性、可用性、完整性）→ 全部以 `平台规则/edusrc.md` 为准，本文件不另立标准。
- **判级档位**（高危 / 中危 / 低危 / 忽略清单）→ 只认 `评级与价值口径/edu-rating.md` 注入的那份，不要按任何 kb 副本判档。
- 两者冲突时 → 以更严者为准；判级仍只认评级文件。

## 验证收敛（与判级联动的边界）

- 越权 / 注入 / 未授权访问：以**库表名、角色变化、返回已填充数据结构**为证明；允许**单发、累计 ≤ 50 条**真实数据实测确认。
- 拿到主机/后台高权限：以证明当前环境/角色为限，不读其他用户/业务数据，**禁止**把当前主机当跳板扫内网。
- 后台功能权限：以证明角色为限，**不实际编辑/增删/篡改**。
- 禁止 DoS、大流量、大规模并发扫描；**禁止**上传/驻留 webshell、后门、可控程序。

## 判级纪律

- `rating_basis` 写 `rating:edu-rating <档位>#<条号> <一句话依据>`；服务端会校验它是否引用本项目生效口径，写别的文件名会被打回。
- 定级只认评级文件的判级条款，且须有实证危害对应（证据不足宁低勿高）；资产价值分级只用于选战场，不用于抬高定级。
- 报告格式仍只认 `web/实战打法/rules/vuln-report-format.md`。
